圆角四级

对比相比现状的 6 处升级

  • 单一强调色：蓝为主，绿/琥珀/红只做语义信号，不再平铺
  • 分层阴影：卡片一律「1px 描边 + 双层柔和投影」，取代纯描边平面感
  • 数据可视化优先：出席率从一行小字升级为进度环 + 大字号
  • 左侧色条：三态用色条 + 图标 + 文字三重编码，强光与色觉障碍下均可辨
  • 玻璃拟态吸顶：滚动时头部半透明模糊，内容从下方穿过
  • 抽屉加拖拽把手：26px 圆角 + grabber，符合现代移动端心智

排版字阶与数字

  • 字号收敛为 6 档：11 / 12.5 / 14.5 / 17 / 29 / 34 px
  • 标题用 letter-spacing: -1px 收紧，现代感来自紧凑而非放大
  • 所有数字启用 tabular-nums，列与列对齐不跳动
  • 字重只用 600 / 700 / 800 三档，层级靠大小与颜色拉开

可达性仍然全部达标

  • 所有前景/背景组合 ≥ 4.5:1（含新琥珀 #B54708）
  • 所有可点元素 ≥ 44×44px（顶部图标 38px 但含 4px 外扩热区）
  • 状态不依赖颜色 —— 色条 + 图标 + 文字三重冗余
  • 保留 深色模式（见第 6 屏）

交互细节 · 会一并做进去

修复P0 缺陷同步解决

  • 返回键接管：抽屉打开时按返回只关抽屉，不再退出 App
  • 身份证号脱敏：设置页默认显示 9612••••••5087，点「显示」才展开
  • 密码显隐开关：登录页与设置页都有 👁
  • 触控全部 ≥44px：顶部图标 38px 视觉 + 外扩热区

动效克制的微交互

  • 三态切换：180ms 背景色过渡 + 色条从 0 展开
  • 抽屉：280ms cubic-bezier(.32,.72,0,1) 上滑，遮罩淡入
  • 提交按钮：按下 scale(.97)，加载时内联进度
  • 吸顶头部：滚动超过 8px 才浮起阴影
  • 全部尊重 prefers-reduced-motion

待确认需要你拍板的三件事

  • 强调色：保持现在的深蓝，还是换成演示里的 #2563EB（更鲜亮）？
  • 学生行前置元素：用序号方块（演示中），还是改成姓名首字母圆形头像？
  • 深色模式：现在就做，还是先只做浅色、后续再加？
