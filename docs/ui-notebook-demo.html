风格拆解

这套质感靠五件事撑起来，缺一件就会「像玩具」而不是「像手账」。

1纸与墨

  • 米黄纸底 #FCF8EC，不是纯白 —— 纯白会让手绘感瞬间消失
  • 墨色 #2E2A24，不是纯黑 —— 纯黑太硬，像印刷不像手写
  • 纸张颗粒用三层错位径向渐变叠出来，不是贴图

2手绘边框

  • 靠 不对称 border-radius 实现：
    255px 14px 225px 14px / 14px 225px 14px 255px
  • 四个角半径各不相同 → 线条「手抖」的自然感
  • 描边统一 2.2~2.8px，太细没手感、太粗像卡通

3荧光笔蓝

  • 外壳元素（按钮、序号、班级名）统一用 #CFE1F7 + #9CC0E8 描边
  • 加 2.5px 3px 的实色偏移投影 —— 模拟马克笔叠涂的厚度
  • 不用柔和阴影，柔和阴影是「现代 UI」的语言，会打架

4马克笔字

  • 拉丁文用 Kalam / Patrick Hand，中文用 站酷快乐体
  • 名字 17.5px、加粗 700 —— 手写体要比常规字号再大一号才看得清
  • 字距略微放松，手写体挤在一起会糊

5便签与涂鸦

  • 提交按钮做成黄色便签并倾斜 -1.1° —— 整个界面唯一的「重」元素
  • 星星、爱心、小猫做低透明度点缀，绝不参与信息传达
  • 线圈与纸孔是「这本子是真的」的关键锚点

!可读性红线

  • 手写体只适合短字符串。马来文假因名（SURAT CUTI SAKIT HOSPITAL/KLINIK）用 13px 手写体扫视很吃力
  • 建议：外壳保持手绘，数据区用清晰体 —— 点上面的「清晰体」开关看效果
  • 31 人的名单每天要扫两遍，识别速度比好看重要
配色（全部通过 WCAG AA）

手账风最容易牺牲的就是对比度 —— 米黄纸底会吃掉一切浅色文字。这套配色逐个算过。
